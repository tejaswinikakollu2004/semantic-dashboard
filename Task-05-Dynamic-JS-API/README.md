# Task 05 - Dynamic JavaScript DOM Logic & RESTful API Client

## Project Overview

This project is a dynamic Product Explorer web application built using HTML, CSS, and JavaScript.

The application fetches product data from the Fake Store REST API and dynamically displays the products using JavaScript DOM manipulation.

## Features

- Fetch products from REST API
- Dynamic product cards
- Product search
- Category filtering
- Price sorting
- Name sorting
- Add to Cart functionality
- LocalStorage for cart data
- LocalStorage for search and filter state
- Loading status
- Error handling
- Responsive design
- Accessible form controls

## Technologies Used

- HTML5
- CSS3
- JavaScript
- REST API
- Fetch API
- DOM Manipulation
- LocalStorage

## API Used

Fake Store API:

https://fakestoreapi.com/products

## Error Handling

The application displays an error message when the API request fails.

Users can click the "Try Again" button to reload the application.
